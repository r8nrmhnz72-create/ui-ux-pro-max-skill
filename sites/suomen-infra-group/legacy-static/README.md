# Suomen Infra Group Oy – kotisivu

Yksi tiedosto: `index.html`. Ei asennettavaa – avaa selaimessa tai julkaise sellaisenaan
(GitHub Pages, Netlify, Vercel tai oma webhotelli).

## Lomakkeen sähköpostilähetys

Lomake lähettää viestit [FormSubmit](https://formsubmit.co)-palvelun kautta.

1. Avaa `index.html` ja etsi rivi `var FORM_EMAIL = "";`
2. Kirjoita lainausmerkkien väliin osoite, johon tarjouspyynnöt tulevat.
3. Julkaise sivu ja lähetä lomakkeella yksi testiviesti.
4. FormSubmit lähettää osoitteeseen vahvistusviestin – klikkaa siinä olevaa linkkiä.
   Sen jälkeen kaikki lomakkeet tulevat suoraan sähköpostiin.
